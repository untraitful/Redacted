Everything runs locally. Settings are stored in this browser only; redacted values never are.

Behavior

Restore mode puts your original values back into the page's DOM tree, inside closed shadow roots. Page scripts reading text see only the placeholder, but the originals are now part of the page. Leave it off unless you need it.
